## 📝 Дополнительная информация

### Режимы работы

**DEMO MODE (рекомендуется для экспертизы):**
- ✅ Не требует API ключей
- ✅ Использует предзаписанные mock данные
- ✅ Демонстрирует полную функциональность
- ✅ Время выполнения: ~5 секунд
- ✅ Бесплатно

**PRODUCTION MODE:**
- ✅ Работает с реальными API
- ✅ Актуальные данные из интернета
- ⚠️ Требует регистрации в SerpAPI и OpenRouter
- ⚠️ Trial версии бесплатны (100 запросов + $5 кредита)
- Время выполнения: 30-60 секунд

### Технические особенности

**Архитектура:**
- Контейнеризация: Docker
- Язык программирования: Python 3.11
- Фреймворк API: FastAPI
- Асинхронная обработка: asyncio

**Интеграции:**
- SerpAPI - получение результатов поиска
- OpenRouter (DeepSeek V3.2) - ИИ-анализ текстов
- Trafilatura - извлечение контента

**Формат распространения:**
- Docker образ (.tar)
- Исходный код (Git архив)
- Docker Registry (pull)
